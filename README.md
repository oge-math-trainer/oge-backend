ОГЭ Математика — Backend

Серверная часть адаптивного тренажёра для подготовки к ОГЭ по математике с ИИ-репетитором. Отвечает за генерацию и валидацию заданий, проверку ответов, формирование анализа входной диагностики и авторизацию пользователей. Данные отдаются фронтенду через REST API.

Стек
Go — основной сервер
PostgreSQL — хранение заданий, пользователей, результатов и прогресса (миграции + PL/pgSQL)
AI-интеграция — генерация и валидация заданий через внешний AI-провайдер (OpenAI-совместимый API)
OAuth 2.0 — вход через Яндекс
Деплой на Render
Возможности
Авторизация через Яндекс с сессионными токенами и ограничением частоты запросов (rate limiting)
Генерация диагностических заданий по темам и подтипам части 1 ОГЭ
Обязательная валидация каждого сгенерированного задания перед показом ученику — проверка корректности условия, ответа и логики решения
Ограничение генерации — не более установленного числа заданий одного типа за запрос (контроль расхода ресурсов)
Фоновый воркер, который заранее готовит пул заданий, чтобы ученик не ждал генерацию в реальном времени
Проверка ответов и формирование ИИ-анализа входной диагностики (слабые темы, типичные ошибки, рекомендации)
REST API для фронтенда
Структура проекта
cmd/         — точки входа (сервер, миграции)
internal/    — бизнес-логика
ai/          — интеграция с AI-провайдером
migrations/  — миграции базы данных
postman/     — коллекция для тестирования API
Конфигурация

Все секреты и настройки задаются через переменные окружения (см. .env.render.example). Ключевые:

Переменная	Назначение
DATABASE_URL	строка подключения к PostgreSQL
AUTH_SECRET	секрет для подписи сессионных токенов
TOKEN_TTL	время жизни токена
YANDEX_CLIENT_ID	идентификатор приложения Яндекс OAuth
YANDEX_CLIENT_SECRET	секрет приложения Яндекс OAuth
AITUNNEL_API_KEY	ключ доступа к AI-провайдеру
AITUNNEL_MODEL	используемая AI-модель
Запуск
Скопируйте .env.render.example в .env и заполните значения:
bash
cp .env.render.example .env
Примените миграции из папки migrations/ к вашей базе PostgreSQL.
Запустите сервер:
bash
go run ./cmd/server

Сервер поднимется и будет доступен по адресу из конфигурации. Проверка работоспособности — эндпоинт /health.
